# 设计：当前快照

> **本文件是当前快照（2026-10-28），不是契约。** 理念是**涌现**出来的：先实践、再记录。它会随结论性改动被改写；修改方式见文末。深度证据留在各 issue 文档里——本仓的 issue 历史就是它的变更记录。

## 1. 两个原子

| 原子 | 是什么 | 组合方式 |
| --- | --- | --- |
| **原子 issue** | 一个复杂问题**不**在内部再分线索，而是拆成**多条独立 issue**（各自 `ask`、各自 `domain`、各自过 `check`） | 类型化**关系**：`blocks` / `part-of` / `relates-to` / `caused-by` / `supersedes`（有向的各有反名；词表固定 9 名） |
| **原子 action** | 一条 issue 的处理流程**没有固定阶段**；一条提交 = 一个动作 | 任意次序、可重复、可按需组合（action 词表可配） |

结构上只有**两端**：起点动作**存在**（默认 `ask`）、最后是**终点**（默认 `conclude` / `apply`）。终点之后仍可继续提交——问题不会被关闭。

## 2. 复杂性在组合里涌现

- **去掉的**：流程引擎、状态机、索引 / DB、树。
- **转移的**：组合语义（边 + 方向 + 折叠）→ 读者；名字纪律（唯一性 / 词表 / alias）→ 作者；一致性 → `check` 与写侧。
- **新增的（自觉的代价）**：配置面。action 词表可配；relation 词表**固定 9 名**（名字层可配已裁定不做，别名只读、只在上游加）。
- **边界**：削的是 **accidental**（记录 / 流程 / 状态同步），不是 **essential**（Brooks）——把一个问题拆成 20 条 issue，问题本身没变简单。
- **工具不教用户**：kiln 只保证提交**能被解析**（起点、终点、`--title`），不评价你怎么工作、动作切多细。

## 3. 七条张力的裁定

| # | 张力 | 裁定 | 证据 |
| --- | --- | --- | --- |
| 1 | 原子（无序集合）vs 叙事（有开端与收束） | 起点是**角色**（存在即可），终点是**位置**（必须最后）；非对称来自「只追加」 | `agent-ux-review` |
| 2 | 「完成」是判定 vs 人的直觉是「结束」 | `status` 的 `✓` 与 `check` 的「完整」同源；终点之后仍可提交，issue 回到进行中 | `agent-ux-review` |
| 3 | 无注册表 vs 写侧拒绝 | 唯一性靠写侧归一化 + 起点重名拒绝；`ask` 要扫 log 是接受的成本 | `issue-uniqueness` |
| 4 | 只追加 vs 可改写 | 一般视图呈现**当前态**；改写 / 撤销不需要声明（声明是可选礼节） | `evidence-fluidity` |
| 5 | 无数据库 vs 别名 / 唯一性 | 改名成本高于同类工具，接受 | `issue-uniqueness` |
| 6 | 人读 slug vs 机器键 | 一把键；歧义在显示侧消除 | `qualified-issue-id` |
| 7 | 「过滤器不是注册器」vs 一致性校验 | kiln 是**过滤器 / 派生视图**，不是注册器：不做全局注册表、不建索引、不分配 id；写侧只在「沉默会污染记录」时拦；`check` 是当前态结构检查 | `design-tensions` |

第 7 条的一句话边界：**能由现存提交重算的一律不注册；不能重算、且错了会静默的才拦。**

## 4. 判据（评审新功能时问的 5 个问题）

1. 加这个 flag / 命令，它是哪条理念的推论？会不会让读侧多一层？
2. 会不会引入需要维护的全局状态（索引 / 注册表 / DB / 缓存）？
3. 会不会把一般视图变成审计（要求保证历史不可变 / 可举证）？
4. 写侧拦它，是因为「静默会污染记录」吗？读侧宽容够不够？
5. 能不能用现有的两个原子 + 9 条关系表达？加名字是否只是标签偏好？

## 6. 如何修改本文件

- 开一条 issue（`ask`）→ `hypothesize` / `collect` → `conclude` 或 `apply` → 回来改这里。**不设「不可动」。**
- 若新结论推翻了这里某条：直接改；让那条 issue 的文档作为证据。本文件只呈现**当前态**（与 `evidence-fluidity` 一致）。
- 每轮 design 结论之后回看一次：这份快照有没有被动摇？
